# Fair Salary Prediction Model 📈

## 📖 About The Project
A machine learning regression pipeline designed to predict perceived fair salaries based on demographic and professional profiles. This project bridges technical data science with social impact analysis by exploring implicit wage biases. Developed for the Machine Learning (APA) course at UPC.

## 📊 Dataset
This project utilizes the **"Status and Just Gender Pay Gaps"** dataset sourced from the Harvard Dataverse. The target variable is `just` (Perceived Fair Salary), a continuous variable that represents the financial compensation respondents consider appropriate for different profiles.

## ⚙️ Pipeline & Methodology
* **Exploratory Data Analysis (EDA):** Deep dive into numerical and categorical variables to find correlations and social biases using Seaborn.
* **Feature Engineering:** Data cleaning, handling missing values, and encoding categorical profiles.
* **Model Training:** Implemented and evaluated various regression models, including **Random Forest** and **Support Vector Machines (SVM)**, to optimize predictive accuracy.

## 💻 Tech Stack
* **Language:** Python
* **Libraries:** Scikit-learn, Pandas, Seaborn, NumPy
